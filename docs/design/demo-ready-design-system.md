# 商用演示就绪设计规范

本规范从五张产品概念图提取，只约束已实现的黄金路径。概念图中的数值仅用于布局，不得作为运行时数据；实际界面必须完全使用当前 API 返回值。

## 设计令牌

- 背景：`#ffffff`；侧栏：`#17233a`；主要文字：`#17233a`；次要文字：`#667085`。
- 主操作：`#16877a`；浅强调：`#e8f5f2`；边框：`#d9dee7`。
- 待处理：`#c98200` / `#fff7e8`；破坏性操作：`#d92d20`；退款数据仅使用克制的红色。
- 圆角：控件 `8px`，主要内容框 `10px`；阴影仅用于需要与背景分层的浮层。
- 间距以 `4px` 为基数，页面区块优先使用 `24/32/48px`，表单行使用 `12/16px`。
- 动效为 `160ms ease-out`；尊重 `prefers-reduced-motion`。

## 文字层级

- 页面标题：28–32px / 700；区块标题：20–22px / 650；正文：15–16px / 400。
- 控件文字：14–15px / 550；表格与辅助说明：13–14px。
- 金额使用等宽数字特性 `font-variant-numeric: tabular-nums`，统一保留两位小数。

## 组件与状态

- 导航：普通用户只有首页、添加本月数据、经营看板、问业务；管理菜单与普通菜单分开。
- 按钮：每屏只允许一个填充色主按钮；次要操作为描边；拒绝操作为红色描边。
- 表单：默认只展示完成当前动作所需字段；错误直接写成业务语言并靠近字段。
- 数据摘要：使用开放行或单一内容框，不使用嵌套卡片和装饰性徽章。
- 加载、空数据、权限不足、服务故障、未启用必须是互斥且可辨别的真实状态，禁止演示数据回退。
- 移动端：底部四项导航，触控目标不小于 44px；管理端不进入普通用户移动主导航。
