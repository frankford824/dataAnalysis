# 概念图与真实界面一致性记录

比对分辨率为桌面 1440×900、移动 390×844。概念图位于 `docs/design/`，真实 Firefox 截图位于 `docs/qa/commercial-v2/`。

| 项目 | 概念目标 | 真实结果 | 处理结论 |
|---|---|---|---|
| 信息层级 | 页面标题、当前范围、核心数字、明细依次展开 | 首页、上传核对、看板和设置保持同一阅读顺序 | 一致；没有加入概念图之外的新功能 |
| 颜色与组件 | 深灰导航、青绿主操作、中性内容面、克制状态色 | 令牌统一为 `#17212b`、`#0f766e`、浅灰边框；按钮状态齐全 | 一致；移除概念图中不必要的渐变和装饰 |
| 数字可读性 | 指标横排、金额和订单数等宽对齐 | 看板显示销售、退款、费用、成本、利润、订单数；店铺表同口径 | 已修正；真实数据来自认证 API，不使用概念假数字 |
| 上传核对 | 一屏看懂店铺、覆盖期、订单、金额和检查结果 | 多店铺显示“2 个店铺”，跨文件检查使用业务文案，失败/等待阻止发布 | 一致；桌面保留更多检查行以支持审计 |
| 设置密度 | 列表为主，编辑时只出现当前任务所需字段 | 页内编辑面板、普通字段直接展示，高级映射折叠 | 一致；没有采用遮挡列表的视觉抽屉 |
| 首次改密 | 单任务、三字段、清晰错误和主按钮 | HttpOnly 会话下强制跳转，390px 无横向溢出 | 一致；实际卡片更紧凑，适合内网登录页 |
| 移动导航 | 普通用户四入口优先，底部固定导航 | 分析师只显示首页、看板、问业务；无上传权限时不显示上传 | 比概念更严格，按真实 RBAC 隐藏不可用入口 |
| 状态真实性 | 等待、失败、成功不能混用 | 缺文件为等待、检查失败进问题队列、锁定月份要求管理员更正原因 | 一致；不显示假成功或静态样例 |
